### AI-Powered Virtual Fashion Try-On

**Fashion Try-On** is an AI-powered virtual try-on application that enables users to visualize fashion products and outfits using generative AI.

The project is built with modern web technologies and integrates **Google Gemini** for AI-powered image generation and fashion visualization.

## ✨ Features

- 👗 AI-powered virtual fashion try-on
- 🧠 Generative AI image processing
- 🖼️ Fashion and outfit visualization
- 👤 User image-based try-on workflow
- 🤖 Google Gemini API integration
- ⚡ Fast modern web application
- 📱 Responsive interface
- 🔐 Environment-based API key configuration
- 🧩 Extensible architecture for future fashion AI features

## 🚀 Run Locally

### Prerequisites

- Node.js
- npm
- Google Gemini API key

### 1. Clone the repository

```bash
git clone https://github.com/opspj007/Fashion-try-on.git
cd Fashion-try-on
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure Gemini API

Create a `.env.local` file in the project root:

```env
GEMINI_API_KEY=your_gemini_api_key
```

**Never commit your API key to GitHub.**

### 4. Start the development server

```bash
npm run dev
```

Open the local development URL shown in your terminal.

## 🤖 AI Integration

The application uses the **Google Gemini API** to power its generative AI workflow.

The AI pipeline is designed to process fashion-related inputs and generate visual try-on results while maintaining the context of the selected fashion item and user image.
